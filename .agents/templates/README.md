# .agents/templates/

This directory contains reusable templates for AI-assisted project work.

Use templates as starting points, not rigid forms. Adapt them to the current project and prompt.

Current templates include:

- `issue.md`
- `project_notes.md`

Keep templates broadly reusable. Project-specific details belong in the consuming project's files, not in this boilerplate repository.

Prefer snake_case filenames.
