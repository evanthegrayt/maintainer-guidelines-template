# .agents/notes/

This directory is for durable project context that helps future collaborators
understand the repository.

Use notes for important information such as:

- current project goals
- architectural decisions
- known risks
- open questions
- non-obvious domain context
- follow-up work that should not be lost

Do not use notes for scratch work, command transcripts, obvious facts, or
information that is already easy to recover from the codebase.

Read and maintain project notes when they are relevant to the current prompt.
This is especially important for significant changes, multi-step work,
architectural decisions, debugging investigations, or follow-up work that may
continue across sessions.

Notes are not a source of truth. Always verify them against the current code,
tests, configuration, and documentation before relying on them.

If notes conflict with the code, tests, configuration, or documentation, trust
the repository and update the notes.
